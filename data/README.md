# Данные

Датасет в git **не хранится**. Каждый кладёт его локально сюда:

```
data/
└── b-mod_lines/
    ├── lines/
    │   ├── train/        # кропы строк
    │   └── test/
    ├── train.easy  train.medium  train.hard
    └── test.easy   test.medium   test.hard
```

Формат файлов ответов: одна строка `<filename> <transcript>`.

**Откуда скачать:** _указать ссылку._

## splits/

Здесь лежат зафиксированные списки имён файлов (`--split-file`).
Тестовый сплит один на всех — его меняют только по договорённости всей команды,
иначе результаты перестают быть сравнимыми.
